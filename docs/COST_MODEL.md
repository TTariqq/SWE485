# Cost Model

All numbers below the "Results" heading are produced by [`tools/cost_model.py`](../tools/cost_model.py). Change an assumption or rate in the script, rerun it, and this document updates. Never edit the generated numbers by hand.

## 1. Variables

| Symbol | Meaning | Baseline value | Source |
|---|---|---|---|
| `S` | Students using the app (pilot: one department) | 400 | Assumption |
| `I` | Instructors | 20 | Assumption |
| `b` | Visits (sessions) per student per week | 1.5 | Assumption (P-01 visits 1–2 times a week) |
| `—` | Sessions per instructor per week | 5 | Assumption |
| `v` | Pages viewed per session | 6 | Assumption: login, slots, book, confirm, my bookings, logout |
| `n` | Sessions per month = (S·b + I·5) × 4.33 | computed | 4.33 = average weeks per month |
| `pA` | KB sent per page, Option A (HTML + CSS) | 30 KB | Assumption; to be measured in M2 |
| `pB` | Option B: SPA bundle 250 KB with a 70% browser-cache hit rate, plus 2 API calls × 5 KB per page | computed | Assumption; to be measured in M2 |
| `o` | Bandwidth overage price per GB | $0.15 | Render, published |
| `inc` | Included bandwidth per month | 5 GB | Render Hobby (conservative, see note) |

**Formulas**

- Hosting per month = fixed instance/storage fees + max(0, bandwidth GB − `inc`) × `o`
- Bandwidth GB (A) = `n` × `v` × `pA` ÷ 1024²
- Bandwidth GB (B) = `n` × (250 × (1 − 0.70) + `v` × 2 × 5) ÷ 1024²
- Development AI cost = input tokens ÷ 10⁶ × input rate + output tokens ÷ 10⁶ × output rate

## 3. How tokens are measured

1. **Context size (measured now):** the script measures the files we give DEVAI as context in every prompt (`RULES.md` + `REQUIREMENTS.md` as a stand-in until feature SPECs exist), using about 4 characters per token, plus about 3,000 tokens for 2 attached source files.
2. **Real usage (from M2 on):** after every DEVAI session, the member adds one row to `tools/token_log.csv` with the input and output tokens shown by DEVAI. These measured rows replace the estimate.

## 5. Interpretation

- **Fixed fees dominate.** At pilot scale both options use well under the 5 GB allowance, so the bill is just the instance and storage fees. **Option A costs about 45% less** than B ($7.25 vs $13.30 per month) because it doesn't pay for a separate database server.
- **Usage barely matters until very large scale.** A sends more bytes per session (full HTML pages), so its bandwidth grows faster. Even so, A stays cheaper until the break-even point shown above, far beyond a single department. Cost is **not** a reason to switch architectures. Scaling limits ([ADR-002](adr/ADR-002-sqlite-on-persistent-disk.md)) would force a change first.
- **The biggest uncertainty is a rate, not usage.** The bandwidth allowance (5 GB vs 100 GB) changes A's cost at ×100 scale, while the pilot result doesn't change.
- **Development AI cost is driven by context re-sent on every turn.** Input tokens are much larger than output tokens because `RULES.md` and the requirements go with every prompt. **One way to reduce it:** attach only the relevant feature `SPEC.md` and the 1–2 files being changed, instead of the full requirements document.
